O **PULSO** é uma plataforma fitness desenvolvida como projeto acadêmico para a disciplina de **Desenvolvimento de Interfaces**. Seu objetivo é oferecer um ambiente simples e intuitivo para auxiliar os usuários na organização de sua rotina de atividades físicas e no acompanhamento de seus hábitos e resultados.

A plataforma reúne recursos voltados para o bem-estar e a evolução pessoal, permitindo registrar treinos, acompanhar a alimentação, monitorar o progresso físico e personalizar a experiência de navegação.

## Funcionalidades

- **Dashboard:** painel com um resumo das atividades e dos registros do usuário.
- **Treinos:** consulta e organização de exercícios, criação de exercícios personalizados e histórico de atividades.
- **Alimentação:** registro de refeições e acompanhamento de informações nutricionais.
- **Progresso:** registro de peso e acompanhamento da evolução física.
- **Perfil:** gerenciamento das informações e dos objetivos pessoais.
- **Acessibilidade:** controles para aumentar ou diminuir o tamanho da fonte e ativar o alto contraste.
- **Carrossel de imagens:** seção visual com imagens relacionadas ao universo fitness.
- **Personalização:** opções de aparência e navegação para melhorar a experiência do usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage para armazenamento de dados no navegador
- Git e GitHub para versionamento e hospedagem do projeto

## Objetivos do projeto

O desenvolvimento do PULSO busca aplicar, na prática, conceitos fundamentais de desenvolvimento web, incluindo estruturação de páginas, estilização, programação com JavaScript, acessibilidade, usabilidade e organização de código.

Além disso, o projeto procura demonstrar como a tecnologia pode contribuir para uma rotina mais organizada, incentivando hábitos saudáveis e o acompanhamento da evolução individual.

## Execução

Para visualizar o projeto, acesse a página publicada pelo GitHub Pages ou baixe o repositório e abra o arquivo `index.html` em um navegador.

## Observação

O PULSO é um projeto acadêmico e demonstrativo. Os dados são armazenados localmente no navegador e não representam um serviço profissional de acompanhamento médico, nutricional ou físico.
